# 工作流程与数据

完整制作可沿“选题 → 大纲 → 材料 → 阅读 → 逐页内容 → 图示设计 → 制作 → 渲染质检 → 迭代”推进，不是每次必须重走的流程。大幅修改按“结构轮 → 内容轮 → 图示轮 → 排版轮”推进，避免在结构未定时反复调整颜色或绘图。
- 有主题直接处理大纲与材料；有 PPT 直接定位修改页。
- 沿用上下文中已知时长、页数、模板与案例。影响结果的未知项集中询问，独立工作继续。
- 使用 outline.md、materials.md、slides.md 保存中间成果，最后保存 PPT 与讲稿。outline.md 保存核心问题、目录、页数、时长和过渡。materials.md 保存论文、版本、实验条件、来源和未核实信息。slides.md 保存每页结论、图示、讲解顺序和依据。三份文件完成后才能进入正式出片。
- 材料记录来源、版本、阅读范围及未核实问题。RAG 资料可以放在主题的 rag/；不作为前置条件。

## 个人资料
优先使用 PPTFLOW_DATA 指定目录。未设置时使用当前任务目录的 ppt-flow-data/；如果当前目录在技能仓库内部，使用技能仓库旁的 ppt-flow-data/，避免把个人资料放进可共享技能。

用 python scripts/init_data.py 创建空白资料；--data-dir 可显式指定。只创建缺失文件，不覆盖已有内容。读取 profile.md 和当前主题；仅选题时读取 topics/_pool.md。

默认模板不含用户邮箱、研究方向、导师要求或历史选题。已授权的个人偏好保存在资料目录，不自动提交技能 Git 仓库。修改既有汇报时以最新文件为准；取消章节时同步目录、过渡语、页码与讲稿，不从旧示例恢复。

## 每轮检查点

- 结构轮结束时，能用目录和每页一句话讲完整场汇报。
- 内容轮结束时，每页都有足够的证据、案例或实验信息支撑结论。
- 图示轮结束时，每条箭头都能用一句话解释，图中没有无法讲解的装饰节点。
- 排版轮结束时，渲染结果中没有溢出、遮挡、断页、错页码或备注错位。
