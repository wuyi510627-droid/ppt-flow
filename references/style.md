# 版式与图示

编辑既有 PPT 时保留模板、校徽、配色与已确认原图；无模板可用东南大学模板（960×540 pt），绿色主色配蓝、紫、橙，同一语义全篇同色。

## 用户确认的样式基线

当前学术组会风格参考《Agent Memory.pptx》和《Agent长程任务中的信用分配.pptx》。保留以下特征：

- 封面有主题、汇报人、日期和校徽。目录明确四个左右的研究阶段，并与后续页码同步。
- 正文顶部保留绿色页眉、章节面包屑和页码。标题直接说明本页要讲的结论或问题。
- 页面采用多个有层级的内容区。常见组合是案例时间线或任务流程、机制图、对比卡片、实验设置、结果、局限和底部过渡语。
- 绿、蓝、紫、橙承担稳定语义。绿色表示主线或正向结果，蓝色表示输入/状态，紫色表示方法或中间机制，橙色表示问题、风险或代价。
- 内容页不追求大面积空白。正文应有足够的信息支撑讲解，但每一块都要有明确作用。使用图形补充关系和动作，避免用装饰性方框制造饱满感。
- 每页的图、文字和讲稿按照同一阅读顺序组织。箭头必须对应真实的信息流、时间流或控制流。

## 图先于长段落
- 一页一个清楚结论，用流程、对比、时间线、关系图或层次图承载解释。
- 正文优先 18–24 pt；密集对比可用 16 pt，但应先删减、转备注或拆页，不不断缩小字体。
- 留白用于分组与阅读顺序，不为“饱满”堆文字。
- 标签尽量一至两行，引线避开文字，箭头对应真实信息流。
- 机制图用原生可编辑形状；数据图用可验证数据和标准绘图库；要求原图时保留原图。

一页的最低内容检查是“结论 + 图示 + 例子/实验信息 + 过渡”。内容页若只有标题、几个标签和空白框，应回到逐页设计阶段补充内容。

标题说明本页要讲什么，面包屑与页码沿用模板，底部总结条按需使用。公式按目标软件选择原生公式、清晰渲染或简短文本，不将复杂数学强行写成纯文本。

讲稿解释图中机制，包含例子和过渡。详细材料写备注，需要时另导出带页码 Markdown；预计用时与稿件长度匹配。
