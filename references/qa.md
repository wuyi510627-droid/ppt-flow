# 交付检查

1. **主线**。目录、定义、章节边界和过渡一致。每个正文页有一个能讲清的结论，有图、案例、比较或实验依据支撑它。
2. **正文文献覆盖**。检查关键路线是否有代表工作、有区别的对照或可信基线。逐篇确认已发表的顶会主会记录、贴合度结论、原文证据、正文位置和用途。核对论文确实能支撑分配给它的小节主张。按论文去重，候选与仅书目单列。
3. **方法与来源**。核对方法输入、输出、步骤、箭头、优点和局限。原图和改绘在备注可定位到论文。教学设定标明。检查案例内部的动作、时间、结果和算式一致。
4. **实验**。核查任务与基准、输入输出、固定项与变化项、基线、指标和预算。区分实际设置、补充设计和教学示例。
5. **版面**。渲染并逐页目检最终稿。修改任务至少检查改动页和受影响的目录、相邻页。检查图文是否按参考风格对齐、投影是否可读、箭头和标签是否对应，以及溢出、遮挡、字体替换、图片裁切。自动文字估算只作辅助。
6. **讲稿与交付**。备注按最终画面顺序解释图和案例，页码、目录、引用和时长相符。确认交付的演示文稿可重新打开，原生图形可编辑。

优先使用宿主渲染器、PowerPoint、WPS 或 LibreOffice。LibreOffice 转 PDF 后可用 `scripts/pdf_to_png.py`。若确实无法渲染，明确说明还有哪些页未目检。
