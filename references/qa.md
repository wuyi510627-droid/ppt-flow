# 交付检查

1. **语义**：标题、图、例子和讲稿相互对应；时间、动作、反馈一致，区分原文与教学简化。
2. **版面**：渲染并逐页检查溢出、断行、遮挡、箭头、图片比例与字体替换。check_fit.py 只作提示。
3. **来源**：方法名称、年份、数字和适用条件能回到原文；未核实内容不当作确定事实。
4. **整稿**：目录与章节一致；页码与页内引用正确；备注及独立讲稿对应最终页序。
5. **可用性**：PPT 可重新打开，图形可编辑；旧稿未涉及页面及指定图片保留。

使用宿主渲染器、PowerPoint、WPS 或 LibreOffice。LibreOffice 转 PDF 后可运行 pdf_to_png.py。缺渲染器时寻找其他可用途径，不能将估算通过说成视觉通过。

只报告影响交付的限制。独立复核在用户要求或复杂汇报确有需要时使用，不把额外审批或代理工作设为所有任务的前置条件。
