# 个人档案（朋友使用时改成自己的）

- 研究方向：agentic RL 中的信用分配
- 导师的要求：围绕问题定义与技术路线组织；讲清实验范式（输入输出、任务与数据集、指标与基线、什么结果说明有效）
- 已讲过的主题：
  - 信用分配（topics/credit-assignment/）
  - Agent Memory（topics/agent-memory/）
- 默认母版：seu
- PPT 样式偏好：参考《Agent Memory.pptx》和《Agent长程任务中的信用分配.pptx》。保持东南大学绿蓝紫橙配色和页眉页脚，页面信息密度要充足。每页优先呈现一个完整论证单元，包括本页结论、机制图、具体案例、必要的论文信息或局限。图文共同支撑论证，按机制和证据选择图示，让听众能顺着页面讲清楚。目录、章节过渡、页面编号和讲稿要与最终页数同步。
- 研究方向来源：assets/research/LLM Agent研究方向.pdf。该文件包含 12 个 Agent 研究领域及其研究问题和技术路线。选题时先询问用户是否已有主题，没有主题时固定推荐 4 个候选，用户明确同意后才进入后续内容。研究方向默认每 30 天检查一次是否需要刷新。
- 组会组织：三位同学轮流主讲，原则上每周一次，每讲三次休息一周，每月约三次。单次汇报约 40 分钟，目标是共同补充 Agent 知识并建立研究框架。内容采用 Problem statement 或 Technical family 两种形式，必须包含技术路线关系和可复用的实验范式。
